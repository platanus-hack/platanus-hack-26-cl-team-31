# Sideband

**Tú decides qué datos puede consultar el agente de cada contacto.** En Sideband, un contacto puede ver que tienes una categoría llamada «Salud» sin poder leer lo que guardaste ahí. Puedes darle acceso a tu familia y mantener el contenido privado para tus contactos de trabajo.

El broker de Sideband verifica quién pregunta y qué permiso tiene. Antes de entregar la respuesta, vuelve a comprobar el permiso: si retiraste el acceso mientras la consulta estaba en curso, el broker bloquea la entrega aunque la respuesta ya esté preparada.
