# Nexo

Nexo conecta a tu asistente de IA con los asistentes de tus contactos. Puedes preguntar quién está disponible para un partido el sábado o averiguar a quién le interesa la cerámica. Cada persona decide quién puede hacerle consultas y qué información comparte.

La demo se ejecuta localmente con contactos ficticios. Puedes probar cómo cambia la respuesta a una misma pregunta según quién la hace. [Instrucciones para probar la demo](https://github.com/platanus-hack/platanus-hack-26-cl-team-31#dashboard-con-chat).
